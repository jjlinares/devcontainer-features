# Dev Container Features

Personal Dev Container Features published under `ghcr.io/jjlinares/devcontainer-features`.

## browser-automation

Installs one exact, checksum-verified full Chrome for Testing build. It can optionally install one exact, checksum-verified standalone `agent-browser` binary configured to use that Chrome.

```jsonc
{
  "features": {
    "ghcr.io/jjlinares/devcontainer-features/browser-automation:1.0.0": {
      "installAgentBrowser": true
    }
  }
}
```

Use a complete Feature version or OCI digest—not mutable `:1`. The current tested pair is Chrome for Testing `151.0.7922.76` and agent-browser `0.33.2`. Supported target: Debian/Ubuntu-based Linux AMD64.

Feature application belongs in CI image construction. Runtime devcontainers should consume the prebuilt image without declaring the Feature again.

Detailed behavior and non-goals: [`src/browser-automation/NOTES.md`](src/browser-automation/NOTES.md).

## Local verification

Requires Docker and the Dev Container CLI `0.88.0`:

```bash
npm install -g @devcontainers/cli@0.88.0

# Repository-local temp storage is required by some Docker Desktop setups.
mkdir -p .tmp
export TMPDIR="$PWD/.tmp"

devcontainer features test --skip-scenarios -f browser-automation \
  -i mcr.microsoft.com/devcontainers/base:ubuntu -u vscode .

devcontainer features test -f browser-automation \
  --skip-autogenerated --skip-duplicated .

rm -rf .tmp
```

The first command runs generated-default and duplicate-install tests. The second runs explicit option scenarios, including a deterministic local fixture controlled through `agent-browser` as a non-root user.
